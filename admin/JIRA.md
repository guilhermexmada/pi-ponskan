# JIRA : Organização de tarefas do Projeto Integrador

[Clique aqui para acessar nosso JIRA.](https://ponskan.atlassian.net/jira/software/projects/SCRUM/summary?atlOrigin=eyJpIjoiMjE4NjgxZTM3MGMzNGJjYmI4ZjQzYjI1MTdkMDkxODEiLCJwIjoiaiJ9)
O JIRA é uma plataforma web para gestão de projetos com equipes ágeis. 

Usamos o JIRA para definir tarefas e prazos do PI, atribuir responsáveis e acompanhar o progresso do nosso projeto. Dentre as estruturas que seguimos, podemos citar Scrum, Sprints e Backlogs.
